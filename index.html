Connect this app to your own Firebase database. You only do this once per device — after that, everything syncs live between the owners' and shopkeeper's phones.

1. Go to console.firebase.google.com → create a project (e.g. yh-boutique).

2. Enable Authentication → Email/Password.

3. Create a Firestore Database (production mode) and in Rules allow signed-in users: allow read, write: if request.auth != null;

4. Project settings → Add a Web app → copy the config values below.
